RESUME FILE INSTRUCTIONS:
=========================
To make the "Download Resume" button work with your real resume:
1. Name your resume PDF file exactly: "resume.pdf"
2. Place it in this exact folder: "assets/resume.pdf"

The website's Download Resume buttons in the navigation bar and hero section are already linked to:
"./assets/resume.pdf"

Until you add your PDF file, the website has a polite fallback alert notifying visitors that the updated resume file is being prepared.
